India District-Wise Rainfall and Crop Yield Dataset (2014–2024)

A professional machine learning-ready agricultural dataset designed for crop yield prediction, rainfall analysis, forecasting, and agricultural analytics projects.

This dataset provides district-level agricultural and climate records across India from 2014 to 2024 and is ideal for Kaggle notebooks, final-year projects, machine learning models, and portfolio building.

Dataset Overview

Agriculture is one of the most important sectors in India, and crop productivity depends heavily on environmental and farming conditions such as rainfall, irrigation, temperature, humidity, soil quality, and fertilizer usage.

This dataset combines these important agricultural indicators into a structured CSV format for data science and machine learning applications.
